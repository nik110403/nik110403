# Nik Khosravipour

My research focuses on monetary economics using macroeconomic data and reproducible pipelines in R and Python.

## Research code

- [treasury-buyback-note](https://github.com/nik110403/treasury-buyback-note) — Frozen-input Treasury buyback arithmetic and descriptive yield-curve comparison; assumptions and limitations explicit
- [argentina-monetary-deepdive](https://github.com/nik110403/argentina-monetary-deepdive) — Replication code for 'Promise versus Delivery': fiscal anchoring of Argentina's disinflation under Milei, 2023-2026 (R, Python)
- [taylor-rule](https://github.com/nik110403/taylor-rule) — Replication code for 'Discretion Over Rules': Taylor-rule estimates, Granger tests and Fed policy departures, 2021-22 inflation surge (R, FRED)
- [warsh-fed](https://github.com/nik110403/warsh-fed) — Replication code for 'Inheriting Discretion': scoring the federal funds rate against four monetary-rule benchmarks for the Warsh Fed (R, Python, FRED)
- [fed-reaction-note](https://github.com/nik110403/fed-reaction-note) — Replication code for the market note 'Calibrated to the Headline' (FRED data, R, Chart.js figures)
- [oecd-growth-thesis](https://github.com/nik110403/oecd-growth-thesis) — Replication package (R, PWT 11.0) for the BSc thesis 'The Determinants of Economic Growth after the Global Financial Crisis in OECD Countries'
- [research-kit](https://github.com/nik110403/research-kit) — Claude Code plugin for source-grounded research: search, PDF to markdown, notes with verified quotes, review, paper build. Every tool works standalone.
